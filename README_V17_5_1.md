# Identidad Grabada V17.5.1

Actualización visual completa basada en V17.5.

## Nuevo acabado

Las tarjetas y los principales contenedores de texto ahora usan:

- fondo marrón oscuro semitransparente;
- desenfoque tipo vidrio;
- borde dorado fino;
- reflejo superior suave;
- sombra profunda;
- efecto hover controlado;
- adaptación específica para celular.

La intención es mantener visible el paisaje de fondo sin perder
legibilidad ni la estética premium de la marca.
