# Identidad Grabada V19.2.3 — Editor visual de virola superior

## Novedades
- Conserva la fotografía cenital real del mate como base del personalizador.
- Permite agregar múltiples capas de texto y subir imágenes/logos.
- Selección de capas y edición por controles: posición angular, radio, escala y rotación.
- Arrastre directo sobre la fotografía para cambiar la posición alrededor de la virola.
- Alternancia entre vista original y simulación visual de grabado.
- Diseño adaptable a escritorio y móvil.

## Ejecutar
1. Extraer el ZIP.
2. Ejecutar `npm install`.
3. Ejecutar `npm run dev` para probar o `npm run build` para compilar.

## Nota
Es una versión experimental. La máscara visual de anillo sirve como guía de colocación; el recorte físico de cada diseño a la superficie metálica y la exportación de archivos de producción aún requieren una etapa posterior de desarrollo y calibración.
