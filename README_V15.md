# Identidad Grabada V15.0 — Hero Premium Argentina

Esta versión modifica únicamente el Hero y el Header de la página de inicio. El resto de la tienda conserva las funciones y páginas de la V14.2.

## Novedades

- Hero de pantalla completa con paisaje argentino, bandera, mate y termo premium.
- Imagen limpia: el texto, botones y beneficios son elementos reales de la web.
- Header transparente superpuesto al Hero solo en la página principal.
- En páginas internas, el Header mantiene su fondo sólido y legible.
- Animación lenta de profundidad en el fondo.
- Entrada suave del texto.
- Beneficios integrados en la parte inferior del Hero.
- Adaptación para celular y reducción de movimiento.

## Probar localmente

```bash
npm install
npm run dev
```

Abrir `http://localhost:3000`.

## Publicar en Vercel

Subí todo el contenido de esta carpeta al repositorio conectado con Vercel. No subas solamente el ZIP.
