# Identidad Grabada V17.6

Versión completa basada en V17.5.1.

## Cambio principal

La página de inicio incorpora un nuevo Hero modular inspirado en la referencia aprobada:

- fondo principal continuo;
- paneles de vidrio muy transparentes;
- bordes dorados;
- carrusel de promociones;
- bloque de beneficios;
- categorías destacadas;
- franja comercial inferior;
- diseño responsive.

El resto de la tienda y sus funcionalidades se conservan.
