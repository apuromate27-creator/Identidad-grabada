# Identidad Grabada V18.1.1

Versión completa basada en V18.1.

## Objetivo

Unificar visualmente toda la página de inicio:

- un solo fondo continuo;
- sin cambios de imagen entre secciones;
- Home más compacto;
- paneles más transparentes;
- menos marrón;
- paisaje más visible;
- menor desplazamiento vertical.

La estructura definitiva del Hero se trabajará en V18.2.
