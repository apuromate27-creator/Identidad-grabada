# Identidad Grabada V15.1 — Header y navegación premium

Conserva el Hero aprobado de V15.0 y mejora la navegación.

- Header transparente sobre el Hero.
- Fondo tipo vidrio al desplazarse.
- Menú fijo y compacto.
