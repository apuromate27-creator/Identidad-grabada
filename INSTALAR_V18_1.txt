INSTALACIÓN CON GITHUB DESKTOP

1. Descomprimí el ZIP.
2. Abrí GitHub Desktop.
3. Seleccioná tu repositorio.
4. Entrá en Repository > Show in Explorer.
5. Hacé una copia de seguridad.
6. Copiá todo el contenido de esta versión.
7. Pegalo dentro del repositorio y reemplazá los archivos.
8. Volvé a GitHub Desktop.
9. En Summary escribí:
   V18.1 - Home Premium
10. Commit to main.
11. Push origin.
12. Esperá el despliegue de Vercel.
