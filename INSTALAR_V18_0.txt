INSTALACIÓN CON GITHUB DESKTOP

1. Descomprimí el ZIP.
2. Abrí GitHub Desktop.
3. Seleccioná tu repositorio Identidad Grabada.
4. Entrá en Repository > Show in Explorer.
5. Hacé una copia de seguridad del proyecto actual.
6. Copiá todo el contenido de esta versión.
7. Pegalo dentro de la carpeta local del repositorio.
8. Elegí reemplazar los archivos existentes.
9. Volvé a GitHub Desktop.
10. En Summary escribí:
    V18.0 - Glass Premium
11. Presioná Commit to main.
12. Presioná Push origin.
13. Vercel hará el despliegue automáticamente.
