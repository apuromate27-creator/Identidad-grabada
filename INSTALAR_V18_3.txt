INSTALACIÓN CON GITHUB DESKTOP

1. Descomprimí el ZIP.
2. Abrí GitHub Desktop.
3. Seleccioná el repositorio Identidad Grabada.
4. Elegí Repository > Show in Explorer.
5. Guardá una copia de seguridad.
6. Copiá todo el contenido de esta versión.
7. Pegalo dentro de la carpeta del repositorio.
8. Elegí reemplazar los archivos existentes.
9. Volvé a GitHub Desktop.
10. En Summary escribí:
    V18.3 - Premium Glass UI
11. Hacé clic en Commit to main.
12. Hacé clic en Push origin.
13. Esperá el despliegue de Vercel.
