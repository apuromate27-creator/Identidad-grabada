# Identidad Grabada V18.6.2 — Globals limpio

Esta versión reemplaza las reglas visuales acumuladas desde V18.0 por un sistema único.

## Decisión principal

El blur alto convertía el paisaje cálido en una mancha marrón. Por eso el nuevo sistema usa:

- fondo casi transparente;
- blur de 2 a 3 px;
- una sola capa;
- sin overlays marrones;
- borde dorado fino;
- sombra suave.

El CSS anterior queda guardado como `app/globals.v18.6.1.backup.css`.
