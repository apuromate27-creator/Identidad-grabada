IDENTIDAD GRABADA — V18.9
FICHA DE PRODUCTO + PERSONALIZACIÓN

BASE: V18.8.3 estable

NOVEDADES
- Selector de cantidad (1 a 20).
- La cantidad elegida se agrega al carrito de una sola vez.
- Nueva opción "Sin grabado".
- Opciones de personalización: Nombre, Frase, Fecha, Iniciales y Logo/diseño.
- Los campos de personalización aparecen solo cuando corresponden.
- Selector de archivo habilitado para elegir una referencia.
- El nombre del archivo queda asociado al resumen de personalización.
- Resumen "Tu selección" antes de agregar al carrito.
- Vista previa adapta el mensaje si se elige "Sin grabado".
- Ajustes responsive de la ficha de producto.
- Se mantienen las correcciones de escritorio y móvil de V18.8.3.

NOTA
En esta etapa se registra el nombre del archivo seleccionado, pero el archivo
todavía no se sube a un servidor. La subida real se conectará cuando armemos
el backend/panel de pedidos.

INSTALACIÓN
1. Descomprimí el ZIP.
2. Abrí GitHub Desktop.
3. Repository > Show in Explorer.
4. Hacé una copia de seguridad.
5. Copiá todo el contenido de esta versión.
6. Pegalo dentro del repositorio y reemplazá archivos.
7. Summary: V18.9 - Ficha de producto y personalización
8. Commit to main.
9. Push origin.
10. Esperá el despliegue de Vercel.
