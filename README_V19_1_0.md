# Identidad Grabada V19.1.0 — Personalizador Pro

Primera versión del editor visual de grabado.

## Funciones
- Vista del diseño directamente sobre el producto.
- Zona grabable orientativa.
- Arrastrar el diseño con mouse o dedo.
- Escala ajustable.
- Rotación ajustable.
- Tipografía seleccionable.
- Carga de PNG/JPG/SVG con previsualización.
- PDF registrado como referencia.
- Modo Editar y modo Vista previa.
- Simulación de grabado distinta para calabaza, madera y metal.
- Posición, escala y rotación se guardan en el resumen del carrito.
- Aviso de que la previsualización es orientativa por tratarse de materiales naturales.

La simulación será todavía más realista cuando cada producto tenga fotografías finales reales y zonas de grabado calibradas.
