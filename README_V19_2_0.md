# V19.2.0 — Prueba del nuevo personalizador de virola

Esta versión conserva la tienda V19.1.1 y mejora el editor de virola con:

- selector Original / Vista grabado;
- área segura de grabado;
- arrastre circular;
- controles de posición, radio, tamaño y sentido;
- acciones rápidas para centrar, escalar y restablecer;
- simulación visual sobre alpaca;
- diseño responsive.

La simulación es orientativa y no reemplaza la validación final del archivo para producción.
