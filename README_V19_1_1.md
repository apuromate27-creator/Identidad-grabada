# Identidad Grabada V19.1.1 — Personalizador de Virola

Primera versión específica para grabados sobre virola.

- Selector Cuerpo / Virola.
- Vista superior dedicada.
- Zona grabable circular.
- Texto curvo.
- Arrastre circular para modificar ángulo.
- Ajuste de radio y tamaño.
- Sentido horario / antihorario.
- Logo sobre la virola.
- Modo Editar / Vista previa.
- Configuración de virola incluida en el resumen del carrito.

Es una primera simulación. La siguiente mejora ideal es utilizar una fotografía superior real y calibrar los diámetros interior/exterior de cada modelo.
